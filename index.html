Cara pasang

  1. Download file .zip skill yang kamu mau. Jangan diekstrak.
  2. Di claude.ai, buka Settings, lalu Capabilities.
  3. Pastikan Code execution and file creation aktif.
  4. Di bagian Skills, pilih Upload skill, lalu pilih file .zip tadi.
  5. Buka chat baru dan minta seperti biasa — AI memakai skill-nya sendiri saat permintaanmu cocok.

Cara tempel (bisa di AI mana saja): buka skill, klik Baca isi skill, salin semua teksnya, lalu tempel di awal chat baru. Di bawahnya, tulis permintaanmu.
